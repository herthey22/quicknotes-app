# QuickNotes App

QuickNotes is a lightweight, responsive web application designed for creating, organizing, and searching daily notes with ease. The application categorizes notes into Personal, Work, and Study tasks, providing visual distinction through custom-styled category cards while persisting all data locally in the browser.

## Features

- **Categorized Note Creation**: Add notes categorized as Personal, Work, or Study with visual color coding.
- **Form Validation**: Real-time error handling preventing empty entries or notes exceeding 200 characters.
- **Live Search**: Filter through notes instantly by keyword.
- **Local Persistence**: Saves all notes to `localStorage` so content survives page refreshes.
- **Responsive Design**: Built with modern CSS Flexbox and Grid, optimizing layout across mobile and desktop displays.
- **Bulk Clear Option**: Clear all notes with a single confirmation step.
